# VELOCITY ZERO

**An original coastal driving experience for the browser.** Chase the horizon along a continuous ~6.87 km island road that threads coast, mountain, tunnel, city, harbour and a sea bridge. Dynamic single-track vehicle physics, PBR cars, licensed racing music and short event sound effects, seven race rules and competitors with their own driving styles.

> **Play it online:** [**https://lgiang517.github.io/velocity-zero/**](https://lgiang517.github.io/velocity-zero/) — or build locally with `npm run build`, then serve `dist/` (or run `npm run preview`). Details below.

---

一款原创的浏览器海岸赛车游戏。沿海岸、山路、隧道、城市、港口和跨海桥驾驶，路线连续，全长约 6.87 公里。

## 启动

需要 Node.js 20.19+ 或 22.12+，以及支持 WebGL2、开启硬件加速的现代浏览器。

```sh
npm install
npm run dev
```

打开终端给出的地址。正式版本使用 `npm run build` 生成，然后 `npm run preview` 预览。除可选字体外，运行素材均在项目内；字体无法加载时使用本机字体。

## 操作

- W / ↑：油门，松开后发动机制动减速；S / ↓：刹车，静止后持续按住进入倒车。
- A、D / ←、→：渐进转向，松手后回正方向盘；车辆保留转弯后朝向。
- Space：手刹；Shift：氮气。
- C：切换车外环绕 / 驾驶员视角；车外可鼠标拖动环绕、滚轮缩放、双击恢复跟车。
- R：回到道路中央，增加三秒用时。
- Esc：暂停；离开窗口自动暂停。
- 手机：左右拇指同时按住方向和油门；可独立操作刹车、手刹与氮气，抬手即释放。
- 手机视角工具：切换驾驶舱 / 车外、回正车辆、+ / − 缩放；车外可直接拖动画面环绕。
- 手机横竖屏均可玩；旋转屏幕、切到后台或失焦会暂停并清空输入，普通窗口高度变化不会打断驾驶。

车辆完全由玩家掌握方向、油门、刹车与氮气，不自动循弯，也不会替玩家预判弯道刹车；松油门会通过发动机制动自然减速。键盘有渐进转向与车速相关的舵量；默认开启 ABS 和车身侧滑稳定辅助，可在设置中关闭。入弯前刹车，侧滑时反打方向，手刹可主动漂移。氮气通过高速驾驶、尾流、近距离超车和漂移补充。

## 已有内容

三种原创汽车、七种比赛规则、两种驾驶镜头、完整倒计时和比赛结算、个人纪录、交通车辆、具有不同驾驶风格的对手。所有比赛模式使用同一条海岛公路，山路模式使用其中一段。车辆间接触按车身矩形、质量和相对速度处理，每次物理更新都防止穿透；所有车辆均使用显示插值。

驾驶采用动态单轨车辆模型，包括连续转向、轮胎侧滑、纵向重量转移、前后轴抓地力、空气阻力、发动机制动、制动、ABS、手刹和湿地抓地变化。对手使用同一驾驶模型，根据前方弯道和附近车辆调整路线，不使用按排名直接修改速度的作弊加速。

车辆通过 Blender 构建，含清漆、反射玻璃、五组分叉锻造辐条、切削亮边、低扁平比宽胎、钻孔刹车盘与固定红色卡钳、制造细缝、原创 V 徽章与 VZ-0606 车牌。左右刹车灯与高位灯随制动亮起。驾驶舱采用曲面皮革仪表台、低位嵌入仪表、实体出风口、带缝线与拨片的D形方向盘，以及分层中控；脚舱、地板和门槛完整封闭，门板前肩收窄并与A柱接合，驾驶眼位前移以扩大前窗视野。首次加载提前准备两种视角的材质和光照。环境采用自然山脊、带针叶边缘的树冠、立面细节、桥梁支撑与分段照明隧道；地形使用本地 PBR 岩石贴图，车辆反射来自海岸 HDRI。道路具有颗粒、修补区域、反光道钉和湿润反射近似。树木、山体、护栏与车辆共享太阳方向和三级阴影；弯道指示牌使用荧光黄底。使用分区批量绘制、近景树木细节切换、多重采样抗锯齿和固定大小粒子池控制开销。素材来源见 [环境素材署名](docs/environment-credits.md)。

配乐采用 Kevin MacLeod 的《EDM Detection Mode》电子舞曲，每次开始驾驶仅播放一次五秒实录发动机启动轰鸣，行驶中没有持续油门或发动机轰鸣；另有倒计时与碰撞提示音；音乐支持暂停续播与重赛归零。声音需用户点击后启动，署名见 [音乐说明](docs/music-credits.md)。

## 交付范围

这是完整可玩的浏览器原型，不等同于商业 AAA 游戏的制作规模和写实程度。汽车与场景布局为原创，使用 CC0 环境贴图及已署名配乐，没有使用真实品牌车型。玻璃和路面采用反射近似，不是完整屏幕空间反射。车辆没有完整的独立悬挂刚体模拟或永久车损，驾驶舱与外壳使用独立的几何细节层。尚不支持联机和手柄。

晴天、黄昏、夜晚、雨、暴雨、雾和变化天气可切换；湿路会减少抓地力，高速经过模拟积水区会进一步短暂减小抓地力。雨滴和水花属于实时视觉近似。

流畅度取决于设备和浏览器。手机菜单支持滚动，按钮适应屏幕安全区，主要触控目标至少 44px。“Balanced”在触屏设备将渲染分辨率限制为 1 倍 CSS 像素；“Performance”关闭泛光和动态阴影。60 帧是目标，不是对所有设备的保证。

## 检查

`npm test` 检查车辆加速差异、松油减速、制动响应、路肩返回、人工变道、干湿路、漂移、氮气、接触防穿透、可驾驶弯道半径、道路接缝与驾驶镜头。操控指标和参考见 [操控验证记录](docs/racing-handling-validation.md)，实际录制的修复前后回放见 [实机验收记录](docs/visual-upgrade-validation.md)。

`npm run build` 检查正式版本能否正常生成。另行通过真实浏览器检查画面、驾驶按键、菜单、镜头、暂停、天气和结算。手机适配覆盖 320×568、390×844、844×390 的浏览器触屏模拟，并实测多点触控；记录见 [手机适配验证](docs/mobile-validation.md)。尚未进行实体手机 Safari / Chrome 验证。

`window.__velocity.getState()` 提供只读运行状态。只有开发环境并带 `?test=1` 的地址才提供测试控制入口，正式版本不包含该入口。
