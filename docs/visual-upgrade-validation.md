# 三维与实机验收记录

验证日期：2026-09-12。运行地址 `http://127.0.0.1:5188/?test=1`，Chromium，1440×900，Balanced。记录的是本机开发预览，未发布线上。

## 100 km/h 松油反打：先看回放，再验证位置

用户反馈100 km/h松开W后找方向，车辆仍向护栏走。浏览器复现使用SOLSTICE GT、默认稳定辅助、干地s=3500，初始100 km/h；全程不按W，按A 0.8秒，松键0.3秒，再按D 0.6秒，松键观察1.5秒。中间截图带来几十毫秒实际间隔偏差，两份JSON保留逐帧真实时刻。录制并检查了连续视频帧和反打结束、最终位置截图。

| 相同操作的实机结果 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 最大横向偏移 | 8.232 m | 4.320 m |
| 护栏碰撞 | 1 | 0 |
| 结束横向位置 | 8.232 m | 3.697 m |
| 最大车身侧偏 | 4.45° | 3.87° |

旧版即使侧偏不大，也会因车身仍朝外而持续横移。松键后再次反打丢失了反向操作识别，高速普通按键过快达到过大舵量。新输入保留短时最近方向，驾驶者明确反打时更快响应并保留反打转角余量；普通高速转角更克制。零输入不会自动选车道、回到旧航向或继续反打。对照录像中修复后的车辆已开始向道路内回收，没有承诺自动回到道路中央。

较短的 A0.5/空0.1/D0.6 对照操作前后均未碰撞；修复后反打更快，最后移至另一侧约2.49m，因此不把某个固定按键组合停在中心作为通过标准。车型、左右方向、80–120 km/h和100–400ms松键间隔的离线覆盖见[操控验证](racing-handling-validation.md)。

## 其他实机检查

- W+S同时按下：从100 km/h，1秒后62.41 km/h，油门关闭、制动压力建立，无碰撞。S不会再被W抵消。
- 松开W：在同一道路从100 km/h滑行3秒至70.54 km/h，无碰撞。不是用撞栏后的速度证明松油有效。
- 两种镜头反复C切换，车外鼠标环绕/滚轮缩放/双击复位可用。驾驶镜头随车身坐标与道路坡度移动。
- 驾驶仪表已从挡风玻璃前降到方向盘后方；车内右下角速度显示缩小，1440×900时位于y=744–866，前方道路保持可见。
- 车辆接触在每个物理步按车身矩形和质量处理，追尾验证无车体重叠并向前车传递动量；所有车辆进行物理步之间的显示插值。
- 新车标、前后VZ-0606车牌、刹车灯已经在浏览器查看；左/右制动灯和高位灯随S制动亮起。
- 海岸、山路、隧道、城市、桥梁以及雨、夜晚、黄昏均做了截图检查。车辆、护栏、树木、地形使用共同太阳方向和三级阴影；Low质量会关闭动态阴影。
- 各区段预热后本机采样约60FPS，绘制276–354次、约155–181万三角（含阴影多次绘制）；这不是所有设备的最低帧率承诺。
- 最终音效按用户要求取消持续油门/转速声音，仅新比赛播放一次五秒启动轰鸣；配乐继续使用《EDM Detection Mode》。浏览器实测解码时长5.000秒、4.207秒仍在播放、5.259秒已经结束，连续三次按下/松开W均不重播，音乐正常，暂停立即取消启动声。来源见[音乐说明](music-credits.md)。

## 视觉制作与范围

车辆用Blender重建，保留原碰撞外廓，加入轮辋内部、制动盘/卡钳、车身缝隙、原创徽章与车牌。具体模型数据见[车辆制作记录](../art/car-visual-upgrade.md)。环境含连续山体、近远景树木、建筑立面、桥梁支撑和隧道分段照明；岩石PBR和海岸HDRI使用本地CC0素材，出处见[环境署名](environment-credits.md)。

道路标线使用曲面细分，不再在急弯被宽三角插值拉歪。最紧弯道半径扩大到约36m，并保持护栏与道路同源。运动镜头不使用速度变化驱动的突然FOV伸缩。真实射线追踪、完整悬挂刚体和永久车损不在本次实现中。

## 驾驶舱封闭与视野修正

驾驶舱含46,362三角形、24个几何体、12种材质和3张纹理；AI车辆不创建内饰网格。脚舱另有216三角形，按3种材质合并成3个绘制批次。新增实体地板、倾斜前脚舱、门槛、脚垫与踏板，避免外壳在内视角隐藏后透出道路。25条脚下射线均先命中不透明车厢表面，前向射线畅通。

原眼位过于靠后，导致顶棚和左门板占据过大画面。眼位从(.35,1.03,-.61)m前移到(.35,1.03,-.40)m，高度与67度纵向FOV保持不变；门板中上部外收约4.8cm，前肩降低、缩窄，前端通过固定饰板接到A柱脚。A柱采用与管体实际截面一致的封口，并将上端埋入头衬，避免外露的管口或球状接头。车门仍与地板重叠封闭。侧面验证64个实体区域均遮挡、10条合理侧窗射线均畅通。

最终[1920×1080驾驶视角](../output/playwright/cabin-final-wide.jpg)、[960×720驾驶视角](../output/playwright/cabin-final-small.jpg)与[夜间视角](../output/playwright/cabin-final-night.jpg)已实际查看。主游戏行驶和C切换验证只有车内/车外两档，车外可正常恢复车身和轮胎；页面异常为0，本机最终采样约60FPS。夜间视角记录336次绘制、约181万三角形，含阴影多次绘制，不是对其他设备的最低帧率承诺。

加载阶段继续预编译并渲染两种内外光照变体，避免驾驶时首次切镜才编译。最初加入预热时的实测为78帧样本，最大16.9ms、95分位16.8ms；该数据属于当时版本的本机记录，不是本轮所有场景的帧时间统计。

## 锻造轮毂与薄胎壁

轮组参考[Ferrari 296 GTB的双辐设计](https://www.ferrari.com/content/dam/ferrari-fcom/old/pdf/CS_296_GTB_final_gbr.pdf)及[296 Speciale的锻造与切削表面处理](https://www.ferrari.com/content/dam/ferrari-fcom/old/pdf/CS_296_Speciale_gbr.pdf)，采用原创五组Y形分叉辐条、凹陷暗桶、金属亮边、低扁平比宽胎、钻孔刹车盘和固定红色卡钳，保留原创V徽章。

原轮轴x±.965m/y.385m/z1.38m和-1.34m、接地半径.375m均未变。详细轮每只11,952三角形/6批，AI简化轮每只4,384三角形/4批；几何按细节等级共享，材质按车独立，最后一个引用释放时销毁共享资源。独立实机检查四轮滚角均为.533333rad、前轮转角均为.27rad、卡钳滚角均为0。主游戏油门与转向检查通过，无碰撞、页面异常为0。

## 五秒启动声

采用已有CC0真实发动机录音中的连续五秒片段，起音和末尾淡出，每次新比赛仅播放一次。默认混音峰值约-26dBFS；游戏实际解码长度5.000秒，4.207秒仍在播放、5.259秒已结束，音乐正常。连续三次踩松W不重播；实机重赛会重新播放，暂停立即停止、恢复不重播。单元检查同时覆盖静音、异步加载取消和旧播放结束回调不影响新播放。素材来源与处理见[音乐说明](music-credits.md)。

最终 `npm test` 的61项全部通过；`npm run build` 成功。构建仍有单个JavaScript包大于500kB的体积提示。
