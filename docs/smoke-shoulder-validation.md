# 轮胎烟雾与路肩转向验证

## 修复范围

本次“安全通道”按用户确认，指最外侧白线外、护栏内的路肩。

### 路肩回正

旧护栏解算只根据相对角速度正负，阻止车辆继续朝护栏转动。当车头已经朝回车道、后车角仍擦栏时，驾驶员回正会缩小车身横向占用，却也被清零角速度，产生一次不必要的转向中断。

修复后先检查转动是否扩大横向车身包络，再决定是否限制角速度。只修改外侧护栏接触约束，不提高抓地、全局转向灵敏度或改变驾驶输入，不放宽护栏防穿透范围。

| 定向检查 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 36 个擦栏回正案例中错误取消角速度 | 36 | 0 |
| 960 个实际路段案例成功完整返回白线内 | 960 | 960 |
| 960 个案例最大护栏包络穿透 | 0 m | 0 m |
| 实际路段案例最长返回时间 | 3.433 秒 | 3.433 秒 |

回正案例覆盖三车型、左右护栏、直路与正负曲率、普通道路与宽桥面。实际路段案例覆盖海岸、港珠澳大桥、独库公路，包含干湿路面、多种初始速度和车头角度。

本次修复的是接触瞬间的操控连续性，**不代表所有恢复都更快**。常规路肩返回在修改前已经能够完成；部分保留有效回正的短按轨迹，完全返回白线的时间略增加约 8–25 ms。用于稳定复现解算分支的轨迹初始设置了 7 cm 接触重叠，不应描述为每次正常驶入路肩都会卡死。

### 烟雾与湿路水雾

- 原先刹车时发出的方形加色粒子，改为边缘柔和、普通透明混合的轮胎烟雾；它由模型两个后轮的实际接地点发出，不从车身中心或排气管发出。
- 开启驾驶辅助时，普通 ABS 直线刹车不产生烟雾；真实侧滑或关闭辅助后的锁轮才触发干燥路面烟雾。
- 湿路按湿度和车速产生水雾，并抑制干胎烟雾；停车后残留效果自然消散。
- 排放按时间累计，粒子池固定为桌面 112、触控设备 64；活动效果仅增加一次绘制，不使用外部纹理。
- 烟雾随夜间、隧道亮度变暗；车辆反射捕获排除烟雾，避免将临时尾迹留在车漆反射中。
- 传送、重开、换车会清除旧尾迹；换车同时清除轮胎源缓存，释放旧车对象引用。
