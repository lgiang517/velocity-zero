# 驾驶操控评分与手机适配验证

验证日期：2026-09-23（Asia/Shanghai）。车型：Aston Martin DB12、Ferrari GTC4Lusso、Ferrari 812 Competizione。

## 结果与评分方法

TypeSafe 真实 API 评分由 **76.6/100 提升至 88.7/100**。这是一套有权重的开发验收评分，不是玩家主观评分、现实车辆认证或实体手机性能评级。

调用 `POST https://api.typesafe.ai/v1/systemone`，返回模型 `jev-1.13.0`。每个维度采用相同的五级 Score 标准（0–4），乘25换成百分制，再按下表加权。评分标准和原始请求/响应均保存在本地报告目录。官方依据：[Score](https://docs.typesafe.ai/primitives/score)、[Composite scoring](https://docs.typesafe.ai/patterns/composite-scoring)。

| 维度 | 权重 | 优化前 | 优化后 |
| --- | ---: | ---: | ---: |
| 转向响应 | 25% | 78.5 | 78.5 |
| 回正与反打 | 20% | 89.0 | 89.0 |
| 制动控制 | 15% | 96.0 | 96.0 |
| 倒车控制 | 10% | 89.2 | 89.2 |
| 手机触控与适配 | 20% | 50.8 | 90.2 |
| 驾驶流畅度 | 10% | 56.8 | 98.5 |

前四项车辆物理未改变，且证据完全相同，直接沿用首次分值。第二次仅请求触控/适配与流畅度两项，避免把模型重新评分的波动当成性能提升。流畅度分值变化包括尺寸同步和重复事件处理修复；前后实测帧率都约60 FPS，不能解读成帧率增加42分。

两次真实请求耗时2.018秒、1.019秒，合计8,669输入tokens、120输出tokens。分项置信度为0.63–0.97，置信度不等于正确率。用户明确允许向TypeSafe发送优化前后测试摘要；未上传源码、车型、音乐或API密钥。评分工具只在本地开发阶段运行，不进入游戏驾驶循环。

## 实测范围

- 852个固定步长工况：720转向、60制动、72倒车；三车型、30/60/100/160/220 km/h、干湿路面、辅助开关及双向输入。既有定速隔离探针，也有保留动力与阻力的自然速度探针；两者不能混作圈速或真实车辆数据。
- 左右镜像误差为0，全部数值有限；刹车覆盖油门/氮气正常，72个倒车工况没有方向反转。
- 默认辅助下，持续转向达到0.01 rad/s横摆阈值需33–150ms；立即反打横摆换向125–150ms；松舵达到轮角<0.001rad且横摆<0.01rad/s需67–375ms。它们是仿真响应，非设备端到端触摸延迟。回正不意味着自动回到原车道。
- 浏览器三款车实际键盘左转、立即反打、松舵及油门+刹车+氮气组合，方向正确、测试段零碰撞。松舵600ms后三车残余横摆均小于0.0005rad/s。
- Chromium手机触控模拟实际发送双指事件，分别验证松开方向仍保持油门、移出按钮后释放、touchCancel、旋屏自动暂停及恢复后输入清零。
- 首轮触控测试的CDP touchEnd点列表写成了油门手指，实际松开了油门；这已作为执行器问题记录，修正后单独验证了预期的方向手指释放，没有把它当作游戏缺陷。

## 已落实优化

1. 使用ResizeObserver和visualViewport监听实际画布变化，同帧合并事件，并跳过尺寸/DPR未变的重复更新。修复前CSS画布390×600时渲染缓冲仍390×844；修复后缓冲390×600、相机比例0.65一致。
2. 修正左右安全区留白，适配六种横竖屏尺寸及44/59px不对称安全区。短横屏标题与车型分行，长车型名和路线名完整显示，核心按钮至少44px。
3. 保留旋屏暂停与清空按键，车库、设置、帮助和返回按钮可通过滚动访问。
4. 道路旁行人从运行时生成和更新入口移除，人物、人物接触阴影和逐帧更新均为零；建筑、人行道、长椅、花盆仍保留。

物理探针与真实键盘测试未证实必须改变灵敏度、抓地或制动力的问题，因此保留现有参数。进一步手感调校需要真机/玩家反馈，尤其是高速短点与连续弯的主观控制负担。

## 验证与边界

- 全量332项测试通过，无失败/跳过；生产构建成功，仅有既存的大于500kB分块提示。
- 六种尺寸：844×390、667×375、568×320、640×280、932×430、390×844；另测左右不对称安全区及CSS单独改变画布高度。
- 844×390手机布局模拟，5秒稳定采样：优化前60.0 FPS / p95 17.6ms，优化后60.0 FPS / p95 16.8ms；两次超过50ms的帧均为0。浏览器无脚本异常。
- 已测的是本机GPU与Chromium触控模拟；未在实体iPhone、Android或Safari上实测。未评估一分钟完整赛道驾驶、主观乐趣或实际触摸延迟。

本地完整证据：`output/playwright/handling-score/`（请求/响应JSON、逐帧记录、852工况原始数据、截图和HTML报告）。`tools/score-handling.py`可复评已记录证据，需要本机凭据并发出真实API请求。
