# 驾驶操控验证

验证日期：2026-09-12。以下为本游戏模型的调校结果，**不是从真实车型遥测标定，也不代表现实车辆性能**。离线测试使用固定 `1/120 s` 步长；无特别说明时为默认初始温度、干燥路面、开启稳定辅助。浏览器回放由主流程单独记录，不把离线数据混作录像测量。

## 当前修复

用户反馈包括松油无有效降速、W 与 S 同按时刹不下来、持续转向甩尾，以及100 km/h松油后较晚反打仍撞护栏。

- 松油立即停止正向驱动力，快速闭合节气门并建立运动挡发动机制动；阻力只取决于本车车速和油门。驾驶者按 S 时优先切断发动机驱动力与氮气，即使仍按 W 也能制动。
- 普通高速键盘修线采用约 `0.78μg`、最大 `8.5 m/s²` 的转角预算，避免0/1按键迅速建立过大的航向变化；主动反打和手刹保留更宽的转角范围。低速满舵保持可用，初响应保持快速。
- 松键不再抹掉最近的操舵方向：0.6 s 内明确按相反方向时，恢复快速反打起舵，保留0.65 s反打转角窗口；方向机反向段加快。松键始终输出零方向，不延长无人输入的反打。
- 默认稳定辅助根据实际前轮角、车速和车身侧滑抑制多余横摆与侧滑；普通后驱全油转弯的后轴抓地惩罚上限从18%降至4%。手刹或关闭辅助时保留滑移。
- 铺装路肩抓地在距道路中心8.1–9.2 m间平滑降至82%，避免原1→0.68的突变。护栏接触保留向内脱离速度与回转，不因车尾仍触栏而抹除回正操作。

## 为什么回转归零后仍会撞栏

车身停止继续旋转，不等于行驶方向已经回到路内。此前100 km/h较晚反打场景中，回转角速度早已过零，但旧航向仍朝向护栏，横向位置继续向外；反打状态又在松键时被清空，导致再次反向起舵偏慢。只检查低侧偏角或回转角速度不能证明位置可控。

当前位置回归直接使用实际赛道s3500：100 km/h全程松W，原方向0.8 s、松键0.3 s、反方向0.6 s，再松键1.5 s。表中记录的是最大向外偏移与开始向内的时间，**不要求也不声称车辆自动停回道路中央**。松键间隔扩大到0.4 s后，最大向外偏移分别为4.43 / 4.66 / 3.72 m，均无碰撞。

正式回归覆盖三车型、80/100/120 km/h、左右方向及0.1/0.3/0.4 s松键间隔，共54组：均不撞栏，最大向外偏移小于6 m，并确实开始向内移动。另对0.3/0.5/0.8 s初次转向和0.3/0.6 s反打做网格检查，确认反打过短仍可能继续向外，反打过长仍可驶向另一侧。保持这些错误后果，不能通过自动回车道掩盖输入时机差异。

## 其他验证与边界

固定半径35/60/120 m，左右方向、干湿路共36组中等负荷过渡测试：建立转向后收油0.6 s、保持小油门、逐步松舵并开油出弯。转角只在开始前计算一次，不根据道路位置修正。全部无碰撞或无故反向回转；最大侧偏角GT1.67°、KAZE R1.08°、V8 2.15°。这些结果不代表极限圈速或自动守住圆弧。

另有288组开放试车场测试，覆盖持续W+A/D、持舵骤然松油和释放方向，无须精确反打序列；侧偏角均低于0.1 rad，松方向0.6 s后回转角速度低于0.01 rad/s。该测试关闭护栏接触以隔离轮胎失稳与碰撞后的旋转，不据此声称任意速度、持续按方向都能留在实际道路内。

W+S覆盖三车型和10/25/45 m/s：每步都减速，结果与只按S完全相同。输入层仍保留原始油门、刹车与氮气字段，制动优先发生在动力层。无道路预瞄转向、目标车道对齐或自动线路制动；持续错误输入仍能撞栏。

RPM使用轮速、0.375 m轮胎半径、3.75主减速和六挡齿比3.3/2.35/1.72/1.31/1.06/0.87连续计算；约7000 rpm升挡、2800 rpm降挡，保留0.13 s换挡断油。三车五次升挡均无超过40%的转速断层，停车900 rpm。齿比服务转速仪表与挡位显示，推进力仍使用原功率模型；按最新需求，行驶中不再播放转速音效。

相关回归位于 `tests/keyboard.test.js`、`tests/driving.test.js`、`tests/playability.test.js`。当前整合后的 `npm test` 共52项通过；视频画面和实际按键时延另见[实机回放报告](visual-upgrade-validation.md)。

## 参考原则

- [BeamNG.drive v0.26](https://www.beamng.com/game/news/patch/beamng-drive-v0-26/) 区分减少过度转角的转向不足辅助与控制转向速度的高速辅助。本游戏参考分别调校范围与响应的思路，未复制其算法。
- [iRacing BMW M4 GT3手册，第18、22页](https://s100.iracing.com/wp-content/uploads/2024/07/BMW-M4-GT3-Manual_V3.pdf) 讨论收油过渡、差速器预载和转向稳定性。本游戏采用平顺过渡目标，未标定该车型差速器。
- [Driver61：Maximising the Exit Phase](https://driver61.com/uni/corner-exit/) 强调有限抓地与转向、加速间的平顺过渡。这些来源提供调校原则，不提供本表性能数值。
