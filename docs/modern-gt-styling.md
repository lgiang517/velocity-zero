# 现代GT后半车身造型 — 2026-09-14

用户反馈：前一版虽消除了结构缺陷，后盖/侧围仍像老式轿跑；要求参考BMW M8、Aston Martin DB12的现代GT体量。此次以造型改进为目标，不将单纯接缝测试通过等同于外观达标。

## 实施方向

- 抬平后盖，使末端从实际Y=.806m提高约82mm，后窗至尾端落差149mm降到67mm。尾缘采用22mm源曲面上翘，保持共用位置/切向/法线。
- 增加后轮上方宽缓的后肩体量，实际宽2.089m→2.165m；尾部上缘略收窄1.876m→1.836m。尾/肩比84.8%，不继续收窄。
- 侧门下半段内收约26mm，上腰线保持稳定，形成宽缓凹面；后肩峰限制在轮拱区域，不伸入后盖形成双筋和小槽。
- 下保险杠收进后肩内侧，形成更清晰的尾部层次；车牌凹槽按整块实体车牌的实际包围盒贴合，保留VZ-0606实体牌照。
- 贯穿细线灯改为左右独立展开的双层细长灯片，灯壳继续依实际保险杠曲面按法线偏置。
- 后半顶棚/C柱按统一连续形变轻度包圆；原前部驾驶舱、侧窗下沿与完整后窗下边界固定，避免破坏此前修好的接口。

## 验收原则

BMW/DB12官方照片用于侧后体量、尾盖斜率、后肩/尾收关系对照，不作为厂家工程尺寸或精确复刻承诺。继承原装配、轮轴、镜片可见性、实体厚度和曲面门禁。灯壳采样覆盖从旧固定±.87m改为实际灯壳bbox的95%和两端/中心；0.5mm贴面、0.75mm跨面、3°法线及其他绝对误差阈值不变，并增加漏端、错误偏置反例。

第一次候选的后窗外侧确有4.93mm谷底回升，已修正，不通过放宽旧肩线测试接受它。第二轮之后将隆起包络限制在后轮区，旧/新几何门禁全部恢复通过。
