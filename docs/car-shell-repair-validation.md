# 2026-09-13 后窗与车尾修复验收

用户云端后上方截图暴露两类问题：过大的后窗和过细的窗框让车看起来像敞篷；Lux 生成后壳的凹折、尾灯和排气残留形成熔化般的表面。直接读取 GLB 三角索引和节点矩阵确认车顶 768 个三角面全部朝外，单独改成双面显示也不改变问题，因此没有使用全车 DoubleSide 掩盖模型缺陷。

## 最终改动

- 保留原车顶和 Lux 前中段，收小后窗、加宽后柱，加入后窗台、密封边和七条细除雾线。
- 玻璃使用烟灰色与更清楚的角度反光，仍可透视内饰。无新增透射渲染或贴图。
- 局部重建后翼子板后方的尾门、尾面、灯带、扩散器和中空排气，封闭上方与后方观察时会露出的内腔。前后 VZ-0606 和全部轮心、轮胎尺寸保留。
- 深色尾部细件合并，最终 87,460 三角形、51 primitives、3,100,944 bytes，比旧模型多三个 primitives。
- 模型 SHA256：`b2a0050952713a7c6d01a65a909404cefff90b523a1cd4b35d3b0bad0865e34d`。加载 URL 使用 `?v=b2a005095271`，避免网站升级后浏览器继续读取旧 GLB。
