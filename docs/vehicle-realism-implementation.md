# 真车对照后的实施方案

目标：消除已实测的尾角错位和曲面断裂，改正GT轮胎、后视镜及内饰装配比例，达到实际游戏多角度可审查的质量。原9a7a资产仅作失败基线；不以现有152项通过自证。

1. 单一尾部母曲面：上盖与侧围采用相切截面，统一纵向边界采样；保险杠取消独占45mm退缩。所有尾部板件使用同一平面圆角/顶部圆角映射。真实板缝在光顺外形确定后设计，不用宽补条掩盖错位。
2. 外皮法线由母曲面导数确定，实体回边不参与外皮平均法线；灯壳、密封和灯片从同一保险杠面向外按法线偏置，禁止固定世界Z贴灯。
3. GT轮胎基准前275/35R21（R=.36295m,W=.275m）、后315/30R21（R=.3612m,W=.315m）。保持轴距与轮距的XZ，轮心Y=R+.004m，同步轮拱/内衬和滚动半径；四轮尺寸合同升级并明确区分历史模型。轮圈外唇与胎圈座口径分开。
4. 新镜壳采用非对称翼形截面、上下壳、密封、折叠关节与实际安装座；按原驾驶员眼点检验镜面无遮挡。保留环境反射，不冒充实时后方画面。
5. 内饰门板上沿/A柱脚/仪表台端盖按连续搭接修整，保留原驾驶眼点和控制位置。模型几何通过后再调材质，不用光照掩盖。
6. 独立读取导出GLB验证全部尾部边界位置、极限切向/法线和灯壳贴合；旧资产须失败，真实有曲率的曲面不能被“离边3mm法线差”误判。边界样本声明须实际落在导出三角面上。
7. 分阶段灰模/法线/旋转条光与BMW M8、DB12官方照片并排目视验收，再完整360、近景、极限转向、驾驶眼位、天气、功能、移动音乐和性能检查。候选输出始终隔离，质量未通过不替换正式资产、不发布。

官方参考与失败证据见 vehicle-realism-review.md；官方图片只保留在本地审查输出。
