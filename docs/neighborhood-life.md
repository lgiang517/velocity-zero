# 街区步道与居民活动

2026-09-19，本地实现；未发布云端。

原有住宅入口台阶止于草地，路侧没有连续步道，也没有居民活动。保留现有19户位置和主体，在两片住宅聚集区建设约1418 m连续步道，并接通全部入户路径。连接段参考实际地形三角面，使用实心落地台阶，新增台阶最高16 cm；住宅平台内的L形铺面连接门口与楼梯。

生活物件包括3处条纹遮篷咖啡座、12辆自行车、19张完整长椅、38个花盆和12处阳台晾晒。门牌与招牌合用512×256文字图。长椅整体向平台前侧移动0.95 m，解除原有花池重叠，入口净宽仍为1.45 m。

居民仅沿步道往返，有步态、驻足和平滑转身。32名候选居民按距离激活；手机最多12名，低画质6名，桌面均衡18名、高画质24名。角色为简化的立体人物，供驾驶场景使用。手机不增加角色阴影投射；小型接地软影单独一个实例化批次。所有动画复用游戏时间和现有更新循环。

## 文件与预算

- `src/neighborhood-paths.js`：步道、入户连接、真实铺面路径与植被避让；25,584三角面、26个空间批次，无每帧更新。
- `src/neighborhood-props.js`：合并的生活设施与门牌；31,832三角面、10个空间批次，近景通常2–3个批次。
- `src/neighborhood-people.js`：共用几何和实例颜色；人物与软影合计2个批次，手机按距离限制人数。
- `src/neighborhood.js`、`src/scenery.js`、`src/world.js`：统一接入，后续草木与石块避开步道。
- `src/roadside-buildings.js`：平台内入口铺面、咖啡座通行空间、长椅位置。

## 验证

238项回归全部通过，生产构建和diff空白检查通过。六个固定视角与居民动态截图无页面错误。两秒间隔观察居民位置和步态变化；入户连接、最高台阶、护栏净距、长椅摆放、暂停/转身和远处隐藏均有对应检查。

本机844×390触屏模拟，DB12/晴天/均衡画质，三个住宅路段各预热2.5秒后持续触控油门采样5秒：

| 路段 | FPS 前→后 | P95 ms 前→后 | 超过50ms |
| --- | --- | --- | --- |
| 沿海 | 60.1→60.2 | 16.8→17.2 | 0 |
| 村镇 | 60.2→60.1 | 16.8→16.9 | 0 |
| 镇区 | 60.1→60.1 | 16.8→16.9 | 0 |

该结果是本机浏览器模拟，不是实体手机性能保证，也不是转向成绩；单纯持续油门脚本会在部分弯道接触护栏，前后碰撞计数相同。触控松开后输入归零，移动反射捕捉保持关闭。
