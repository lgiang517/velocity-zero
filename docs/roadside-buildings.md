# 沿路住宅优化

2026-09-15，本地实现。

2026-09-19 继续接入连续步道、居民和生活设施；最新实现与验证见 [neighborhood-life.md](neighborhood-life.md)。下方为原住宅改造记录。

## 原因与实现

原64栋城市盒体只采中心地高，入口沿着道路前进方向；所有窗户仅为平面着色器图案。改为19栋临路低层住宅与8栋远景楼：近景按平台9点采样并限制坡差，完整含楼梯包络与道路保持净空；远楼也采地基范围并朝路放置。

新增实体墙段及凹入玻璃、窗框、窗台、门楣、可通行阳台门、屋檐、排水管、烟囱、挡土基座、花坛、信箱、长椅和逐级落地楼梯。入口不进入行车道；未改变道路几何、赛道或车辆物理。

房屋材质为3套Poly Haven CC0 1K PBR纹理，总2,063,641字节；来源详见roadside-texture-credits.md。灰泥保留凹凸与微小色差，按涂装明度重新着色。近景门窗框等细节按100/170/240m距离区间隐藏，空间实例批次减少重复几何。

## 验证

- 184项回归测试通过，最终阳台门改动后3项建筑检查再次通过；最终生产构建与diff空白检查通过。
- 净空、朝路方向、真实几何顶点包络、楼梯接地、远处隐藏细节通过。
- 四种房屋近景、4个道路旁取景、3个真实驾驶位置及夜景截图已检查。
- 本机844×390移动端模拟，balanced三个驾驶位置读数均约56 FPS，无页面异常；读数不代表实体手机性能。
- 当前19栋近景住宅、413个窗洞、6708个实例、104456个近景建筑总三角形、174个空间批次。多数细节在远处隐藏。
- 审查页 output/playwright/roadside-realism/index.html，截图及验证脚本同目录。

此轮实现不是照片扫描场景，外围原有树木和地形仍是游戏资源；照片级植被和整条街区扫描不属于本次实现。
