# 转向与起步问题复盘（2026-09-06）

> 历史版本记录。当前操控、路线与验证指标见 [最新操控验证](racing-handling-validation.md)。

本记录取代 road-safety-validation.md 中旧版键盘自动沿路稳定的描述。

确认原因：
1. 旧 DrivingInput 自动跟随道路，并将方向键定义为2.8m/s横移。以15m/s沿弯道持续按方向键，约3.32秒撞向内侧栏，属于控制语义错误。
2. 物理在3m/s、输入辅助在6m/s硬切换。旧侧向加速度单步跳变约4.9–7.2m/s²；部分车型舵量瞬间降低72%。
3. 夸张车身俯仰与额外镜头脉动放大起步不稳感。

修改：方向键只控制平滑方向盘舵量，取消道路自动转向、积分横移与第二套驾驶控制器。根据轮胎抓地能力限制高速过量舵角；低速运动学与轮胎动力学连续过渡。ESC只抑制过量横摆，不改变道路行驶意图。修正道路坐标偏航使用实际沿道路推进量；降低俯仰幅度，移除持续镜头脉动。重型车方向盘响应恢复到与其他车相近的水平，保留质量、动力和轮胎差异。

验证：
- 18项测试通过；生产构建通过。
- 三车、左右曲率0.01/0.02/0.03、15m/s，匹配舵量并小修正持续8秒，无护栏碰撞，末端偏移小于1m。
- 起步跨3/6m/s，侧向加速度单步跳变约GT0.077、Light0.140、Muscle0.098m/s²。
- 松键横摆角速度衰减，保留已改变的世界行驶方向；反打不会瞬间横向平移。
- 真实浏览器键盘起步至约75km/h，短按左键后反打，零碰撞，约60FPS。录像 driving-fixed.mp4。
- 回放 steering-replay.webm 检查起步、长按、松键与反打；其前段含启动等待。短片保留最近一次驾驶动作，未修改游戏画面。

驾驶说明：现在是手动方向盘转向；弯道需要随弯曲程度调节方向并提前减速。松键回正前轮不意味着车身会自动吸回道路或车道中心。
