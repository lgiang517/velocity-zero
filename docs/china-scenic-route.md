# 中国主题景观与远山改进

2026-09-19，本地实现；本轮未发布云端。

在现有约 6.87378 km 的闭环道路上加入港珠澳大桥主题、川西峡谷高架和独库雪岭，同时重做远山形体、层次与色彩。这是适配驾驶环线的主题化缩尺景观；不代表三地真实地理连接，也不复刻真实道路长度、桥梁尺寸或路线。道路中心线、现有护栏和车辆物理保持原有契约。

## 场景内容

| 场景 | 环线范围 | 实现内容 |
| --- | --- | --- |
| 港珠澳大桥主题 | `t = 0.90–0.993` | 沿原道路弯曲与坡度铺设连续箱梁；两座 H 形主塔、塔顶中国结意象、96 根斜拉索、桥墩与路灯，主通航跨保持开敞 |
| 川西峡谷高架 | `t = 0.31–0.385` | 连续箱梁、双肢高墩、墩帽与横系梁；峡谷下切至路下约 64 m，凸显跨谷高度 |
| 独库公路主题 | `t = 0.39–0.475` | 天山雪峰、裸露岩脊、三处高山草甸、路侧山体切坡、挡墙、红白雪地导向桩和 G217 里程标识 |
| 远山 | 环线远景 | 重塑山脊、沟谷与地层色彩，远山雾与天气同步；原有 68,040 三角面、21 个分块的几何预算不变 |

港珠澳段借用青州桥“中国结”的识别特征；未同时复刻风帆塔、海豚塔、岛隧及整座大桥。川西段是山区高墩箱梁高架的通用景观表达，不冠以兴康特大桥等具体实桥之名。独库段的雪峰与草甸来自天山道路景观参考，路牌里程为场景化标识，不用于真实导航。

## 文件与资源

- `src/china-bridges.js`：两段桥梁的结构、桥塔、斜拉索和桥上附属设施；沿现有道路采样生成，按空间合并。最终为 29,780 三角面、19 个批次、44 个墩体、2 座桥塔、96 根斜拉索和 54 盏造型路灯；不新增真实光源或桥梁纹理。
- `src/duku-scenery.js`：雪山、草甸、切坡与路侧细节；当前为 14,934 三角面、15 个批次，无额外资源下载与独立每帧更新；里程文字使用本地生成的小型图集。
- `src/terrain.js`、`src/world.js` 等接入文件：峡谷地形、远山形体与色彩、天气雾同步及场景组装；以最终差异为准。
- `output/playwright/china-scenic-route/index.html`：响应式验收页，8 个主题场景视角与 3 个远山视角使用原图滑杆比较。
- `output/playwright/china-scenic-route/results.json`：最终回归、构建与性能实测，供验收页自动读取。

## 验证

主题场景截图使用 1280 × 800、均衡画质和固定相机。8 组视角覆盖港珠澳驾驶与主跨、川西驾驶、独库入口与雪岭，以及三个主题路段的外部全景；远山比较包括山脊全景、海岸地平线、北侧接近视角。图片保留完整画面，不裁切、不调色。

全量回归共 259 项，259 项通过、0 失败、0 跳过；生产构建通过，保留较大 JS chunk 的体积提示。最终主包为 844.64 kB，gzip 后 242.70 kB。此结果对应最终矿物表面起伏强度 0.75 的版本。

| 项目 | 结果 |
| --- | --- |
| 最终全量回归 | 259 通过、0 失败、0 跳过，耗时约 9.66 秒 |
| 生产构建 | 通过；58 个模块完成转换，保留原有较大 JS chunk 体积提示 |
| 固定视角 | 8 个主题场景视角与 5 个远山检查视角均无记录到的页面错误；展示页选取其中 3 组远山对比 |
| 场景几何检查 | 桥面贴合道路坡度并位于路面下方；低位拉索避让护栏；桥墩基础嵌入谷地；峡谷过渡不侵入邻近道路；独库场景保持静态预算 |
| 手机横屏模拟 | 四路段前后均约 60 FPS，所有采样中超过 50 ms 的帧数均为 0 |

本机 GPU、844 × 390 浏览器触屏模拟，DB12、晴天、均衡画质。每个路段预热 2.5 秒，再持续触屏油门采样 5 秒；前后各采样一次，每次记录 301 帧。FPS 根据实际采样时长计算，P95 为排序后的帧间隔第 95 百分位，单位 ms。

| 路段 | FPS 前 → 后 | P95 ms 前 → 后 | 超过 50 ms 前 → 后 |
| --- | --- | --- | --- |
| 远山路段 | 60.1 → 60.1 | 16.8 → 16.8 | 0 → 0 |
| 川西高架 | 60.2 → 60.1 | 16.9 → 16.8 | 0 → 0 |
| 独库公路 | 60.1 → 60.1 | 16.8 → 16.8 | 0 → 0 |
| 港珠澳大桥 | 60.2 → 60.1 | 16.9 → 16.8 | 0 → 0 |

脚本只持续油门，没有转向操作，部分弯道会接触护栏；远山／川西／独库／港珠澳四路段的前后碰撞计数都为 0／8／9／0。两轮全部路段松开触控后，指针数和油门、刹车、转向输入归零，移动端动态环境捕捉保持关闭。前后性能采样均没有记录到页面错误。

性能采样时矿物表面起伏系数为 4.8，随后仅将该系数降至 0.75，纹理读取和着色指令结构未改变。最终截图、259 项回归和生产构建对应 0.75；此次系数微调后没有重复性能采样。这些数字只描述本机浏览器的短时模拟，不能替代实体手机实测，也不代表长期稳定性或驾驶成绩。

完整证据保留在同目录 `full-tests.log`、`build.log`、`after.log`、`mobile-before.log`、`mobile-after.log` 与 `../distant-mountains/after.log`。`results.json` 包含原始测试／构建日志、场景与性能 JSON、采样方法、备份校验数据以及未舍入数字；验收页直接读取 `summary` 和 `mobileComparison`。

夜间低画质与雨天高画质各检查三个主题路段，六个组合均正常渲染，中文区域名称正确，运行错误为 0；证据见 `weather-smoke.log`。雪山轮廓仍偏平滑，本次为主题场景初版，不作为写实效果定稿。
