# 车轮滚动与接地修复

2026-09-19，基于已发布 66accf8 检查三款实际 GLB，并记录后视、侧后视动态画面。

## 已确认原因

12 个轮子的轴线、旋转枢轴和方向正常。旧版将轮子与卡钳一起放在有俯仰、侧倾的车壳层，导致加速时后胎离开模型地面约 47–52 mm；极限组合姿态可产生约 126 mm 离地、158 mm 穿地。加速与制动的视觉俯仰方向相反。默认正后镜头高约 3.53 m，且夜间路灯不投射车辆阴影、低档不启用太阳阴影，进一步削弱轮胎接地感。

## 修复

四轮及全部卡钳放入独立 wheelRig，随道路坡度定位；仅车壳围绕轮轴高度俯仰和侧倾。加速抬头、刹车点头，转弯时向外侧倾。主车和其他车辆的道路高度补偿为 25 mm，与沥青实际表面一致。默认后视镜头俯角从 .33 改为 .25，平路眼高约 2.88 m；保留正后方向及用户拖动视角。

每车增加一个 28 顶点 / 20 三角面的柔和接触阴影，覆盖车底及四胎，不增加灯光、纹理或阴影贴图。隐藏远车跳过更新；换车与离开比赛释放资源；反射捕获同步隐藏自身接触阴影。

## 验证

- 本地完整测试 315/315 通过，生产构建通过。
- 实际三车 GLB 在正反转、四个轮转相位、转向、极限车身姿态及道路坡度下验证：车身姿态引入的轮胎接地点漂移消除；原网格离散误差小于 1.5 mm。
- 前后轮卡钳不随轮盘滚动，原轮径、自转速度、车辆操控参数保持。
- 录制 6 段实际 WebGL 动态视频：修复前 DB12、修复后三车侧后、正后、夜间低档。过程包括起步、低速加速、刹车和停稳；录制无脚本或 GPU 错误。
- 运行时审查确认主车、对手、交通车、车库、暂停、驾驶舱和反射资源生命周期完整。

动态验收页：`output/playwright/wheel-motion/index.html`。手机触控模拟、生产运行及发布版本回读在同目录 JSON / 日志记录。正后方向会被车身遮住轮毂侧面，因此同时用侧后连续帧核对转速，而非仅看一张截图。
