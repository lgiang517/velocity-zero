# Lux3D / Blender / Three.js 图形升级验收

日期：2026-09-13。改动位于本地工作区；本记录不表示已发布至 GitHub Pages。

## 实际资产与画面

- Aholo Lux3D G1 任务 3429656 生成海岸侵蚀岩体，原始模型 33,148 三角形。
- Blender 5.2.1 LTS 实际导入、归一化、修正非金属材质、缩小贴图并生成三级网格：24,000 / 7,000 / 1,400 三角形。最终 GLB 1,507,456 字节，共享一个材质、两张 1K 贴图。原始文件、请求记录、可编辑 `.blend` 和统计在 `art/lux3d/`；复现脚本为 `tools/prepare-coastal-rock.py`。
- Three.js 加载八处道路外侧岩体，检查整个赛道的安全间隔；共享网格和材质，按距离和设备选择细节，精度切换带 12% 滞回。触屏平衡档避开最高精度模型。
- 地表新增土壤和岩层变化；原地形 115,500 三角形分为 25 块，远山 68,040 三角形分为 21 块，按视锥剔除。道路高度、网格边缘位置及法线保持一致，远山取消无效阴影。
- 保留 505 棵树与 1,050 丛草的逻辑摆放，植被预算由 140,252 降至 109,924 三角形、批次由 119 降至 94。近景树冠、针叶和草丛使用动态池，静止时不重复上传，原地转动视角会刷新。
- 细化车漆、玻璃、缎面黑饰件与合金反射；玩家车漆微表面细节随距离淡出，交通车辆保持简单材质。此项不增加纹理、几何或绘制次数。最终保留 ACES 色调映射。
- 道路标线增加基于像素覆盖的抗锯齿；泛光略收敛，使橙色车漆与红色尾灯保持清晰。

跨海桥原有桥底结构未随坡度倾斜，会在陡坡穿出路面形成灰色横条。本轮使桥底板和横肋跟随道路切线；逐段验证上表面低于路面，并重新检查车外与驾驶舱画面。

- 高 → 平衡 → 低 → 高 → 平衡：实际阴影附件尺寸依次为 2048、1024、0、2048、1024，多重采样依次为 4、2、0、4、2；保存低档后重载仍能正常进入菜单和照明，最后恢复平衡。
- 键盘油门和转向正常；驾驶舱可见前路且地板封闭；暂停清空输入、恢复继续比赛。
- 晴天、黄昏、夜晚、暴雨均完成截图和着色检查；暴雨湿度进入 0.9958，灯光与湿路正常。启动声仍为 5 秒，到时停止。
- Chrome 触屏模拟：390 × 844 与 844 × 390，设备 DPR 2.625。实际使用 DPR 1、2x HDR MSAA、3 × 768 阴影；手机平衡岩体 LOD 为中精度与低精度。
- CDP 多点触控：同时按方向和油门时 2 指、双输入；仅松开方向后 1 指且油门保持；全部抬起后 0 指、输入清空。触控切换驾驶舱、旋转暂停和恢复均通过；两种布局无横向溢出。
- 桌面、手机和天气测试均无页面错误或控制台 error。

实际截图与自动化脚本保存在 `output/playwright/lux-final-*`；基线为 `lux-before-*`。这些是游戏运行画面，非宣传海报。手机结论限于浏览器触屏模拟，尚未在实体手机验证。
