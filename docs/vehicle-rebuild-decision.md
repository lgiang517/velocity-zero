# 车辆重建决策（2026-09-14）

## 判断

停止在当前外壳上继续调整后盖、侧围参数。现有方案没有达到用户要求的现代 GT 外形；局部接缝检查通过不能作为造型验收依据。游戏正式资源与云端本轮不替换。

最新改造将后部增高、后肩加宽、尾部收窄及侧面内凹同时叠加，视觉上增加了尾部厚重感与曲面起伏；旧车窗边界与重新塑造的 C 柱没有协调。继续只改这些参数，缺少可靠的整车形态约束。

## 本轮已做与止损

独立新建了一套不导入旧外壳的灰模，文件在 output/gt-rebuild。只输出侧面、正后、后45度三个视角。后45度检查仍见车尾方厚、侧窗布局不协调，因此判定不通过。tools/build-gt-clay.py 仅是失败研究稿，不作为游戏资产生成流程，不继续添加材质、内饰或全套截图测试。

## 推荐路线

优先获取具有明确许可、整车比例已由作者完成的 DB12 模型作为候选基础，然后在 Blender 中做游戏适配。使用单一车型的比例关系，不继续混搭 M8、DB12 与旧模板。

候选来源：https://sketchfab.com/3d-models/aston-martin-db12-732d49c6c79e4d538bd93daf0fc773d3

作者：MattDoesBlender。页面实查标注 CC Attribution，链接 CC BY 4.0；228.7k triangles、141.8k vertices。点击正常下载按钮出现 Sketchfab 登录弹窗。本轮尚未下载文件，也未检查网格、材质、内饰及动画拆分，不能将其称为已合格的替换资产。

需要的外部输入：用户通过自己的账号正常下载原始模型包，放到项目内，或提供已正常取得的文件。无需提供密码。保留作者、来源、许可及修改说明。

## 有顺序的验收

1. 获取后先检查文件是否包含完整外观和可用内饰、车轮与镜子是否可独立处理；不满足关键条件则立即淘汰，避免在错误资产上投入整车改造。
2. 用统一镜头、车轮尺寸及中性灰材质只比较侧面、正后、后45度，与官方 DB12 对应照片核对车顶弧线、后窗/C柱、轮拱和后盖转角。先给出可审查的形态结果。
3. 形态确认后处理拓扑、玻璃厚度、门板与仪表台连接、轮胎与镜座、车牌、车漆和 Three.js 装配；复用件必须适合新车型尺寸，不能强行沿用旧位置。
4. 完成资产后集中做一次360度外观与驾驶舱检查，并验证转向轮、镜子、加载和手机性能。只有发现具体新问题才补测对应角度。生成成功、技术检查通过均不代表外观合格。
